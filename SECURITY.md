# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 2.4.x   | ✅        |
| < 2.4   | ❌        |

## Reporting a vulnerability

If you discover a security vulnerability in **behave-modern-html-report**,
please report it responsibly:

1. **Do not** open a public GitHub issue.
2. Email **mathias.paulenko@outlook.com** with a description of the
   vulnerability, steps to reproduce, and potential impact.
3. You will receive an acknowledgment within 48 hours.
4. A fix will be prepared and a GitHub Security Advisory published once a
   patch is available.

## Scope

This security policy covers the `behave-modern-html-report` Python package
and its bundled assets (CSS, JS, Jinja2 templates). It does not cover
third-party dependencies — report those to their respective maintainers.
